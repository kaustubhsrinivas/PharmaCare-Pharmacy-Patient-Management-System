# PharmaCare — Pharmacy Patient Management System

A fast, responsive front-end project for managing pharmacy/clinical patient data.

## Features
- Patient records
- Doctor assignment
- Appointment date & time tracking
- Medicine and dosage/timing tracking
- Dashboard statistics
- Patient search
- Responsive UI
- Add new patient workflow
- Demo data included

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- No backend or external dependencies

## Run Locally
1. Download or clone the repository.
2. Open `index.html` in a browser.

## Important
This is a portfolio/demo application. It uses sample patient data only and is **not intended for storing real patient/medical information** without proper authentication, encryption, access control, audit logging, backups, and compliance with applicable healthcare/privacy requirements.
